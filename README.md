# Me Encontre

## 📌 Sobre o projeto
Me Encontre é um site pensado para quem está em dúvida entre dois produtos parecidos na hora de comprar. Em vez de mostrar duas fichas técnicas repetidas, ele esconde tudo o que é igual entre os produtos e destaca só as diferenças reais — junto com o preço de cada uma —, ajudando o usuário a responder: "o valor a mais realmente corresponde à qualidade?"

## ❗ Problema
O desafio apresentado para a equipe foi: como ajudar alguém que está em dúvida entre dois produtos quase idênticos (um mais barato e outro mais caro e supostamente melhor) a decidir com confiança? Hoje essa pessoa precisa ler duas páginas de ficha técnica, tamanho, caimento e avaliações espalhadas e repetidas, perdendo tempo para achar o que realmente muda entre as opções.

## 💡 Solução proposta
A solução foi um site de comparação inteligente: o usuário cola os links dos dois produtos, responde 3 perguntas rápidas sobre como pretende usá-lo, e recebe uma tela só com as diferenças cruciais e o custo de cada uma (o que é igual fica oculto, mas pode ser expandido). Quem ainda tiver dúvida pode consultar avaliações reais filtradas por tema, ver um "Termômetro de Arrependimento" (taxa de devolução/queixas de cada produto) e terminar com um veredito final indicando se vale pagar a diferença de preço.

**Usuário:** pessoas que estão decidindo entre duas opções parecidas de um mesmo tipo de produto (ex.: duas versões de um smartphone) e não têm certeza se vale a pena pagar mais pela versão superior.
